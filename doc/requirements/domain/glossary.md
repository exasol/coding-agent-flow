# Coding Agent Flow Glossary

This chapter defines the terms used in CAF documentation and traceability.

| Term | Meaning |
| --- | --- |
| Coding Agent Flow (CAF) | A language-independent workflow tool. |
| OpenFastTrace (OFT) | A tool for analyzing traceability links between repository artifacts. |
| Target Project | Read-only input to a CAF operation. |
| Target Project Path | The caller-supplied path for one Target Project operation. |
| CAF Caller | The actor that supplies a Target Project Path and invokes CAF operations. |
| Work Item Description (WID) | Planning context for an incremental unit of work, such as an issue, ticket, or epic. |
